如何给打印机校色？

本文最后更新于 2025年12月27日 晚上

引子

想做打印机校色很久了，直到最近又买了一台 Epson 打印机，才把这事提上日程，买了色卡以后发现网上几乎没有教程，看了 Profile Prism 的支持后才把整个流程走完，中间也踩了一些坑，所以还是写个小教程方便后来人。

Profile Prism 的官方支持在这里，我这肯定有描述不全的内容，可以对比着看。

材料准备

IT8.7/2 色卡

IT8.7/2 色卡

这是一张 5*7 英寸的照片，可以用来给扫描仪、打印机、相机校色。

市面上有很多品牌在做这样的产品，推荐选择提供参考文件（Reference file）的老牌厂商，因为 IT8 作为一个理论标准，无论在印刷时多么精确，最终的成品依然会有偏差，所以在用色度仪测量后，生成的参考文件就是用来描述这张色卡实际情况的。

ColorRuler 的价格是 $34.99USD，含运费，不过你可以在其他平台看看，价格上会有些变化。

固定的打印流程

包括：相纸、电脑、软件、打印机、打印机中的墨水/墨盒、甚至连接方式（网络还是 usb）

这其中的每一个环节都有可能影响最终的打印色彩，一个校色 icc 只能对应一种流程，任何一项发生改变都应该重新校色。

尤其需要注意的是，软件一定要选择支持色彩管理的软件，比如 PS；并且一定要确保自己的连接方式支持打印机的完整驱动，MacOS 必须通过 USB 连接，安装的官方驱动才能起效，不然就只能用 AirPrint 通用驱动，而这个驱动是无法使用 icc 的，扫描也不能跳过扫描仪的色彩调整，但 Win 即使通过网络连接也可以完整地使用官方驱动，所以虽然 MacOS 以色彩管理优秀著称，在这方面的应用上，我反而推荐用 Windows。

Profile Prism

老牌校色软件，支持扫描仪、打印机甚至是显示器校色。

Profile Prism 软件界面

校色流程

  1. 使用固定流程，在软件和打印机均无色彩控制的条件下，打印一张由 Profile Prism 提供的色靶（target）。
  2. 将色靶和 IT8 色卡一起放入扫描面板中，无色彩控制扫描到电脑上。
  3. 使用 Profile Prism 对打印机校色，对扫描仪校色（可选）。

校色原理

Profile Prism 分析在没有任何软件因素影响下打印和扫描到的图片，首先它会把得到的色卡图片和参考文件进行比对，获得扫描仪的色差（但并不会生成扫描仪的 icc），在此基础上，比对色靶和原文件的差别，得到打印机的校色 icc。

但实操中有很多需要注意的地方。

实操

1. 打印

安装好 Profile Prism 后，可以在目录里找到 priter-target-40.tiff，是在打开打印机色彩管理、关闭软件色彩管理时使用的； priter-target-bright.tiff，是在打印机和软件均关闭色彩管理时使用的，因为有些品牌打印机在关闭自身色彩管理后，输出的色靶会很黑，丢失信息，软件提供了这个亮一点的版本。我在尝试打开打印机色彩管理后，发现校色出来的产品很黑，可以先选择均关闭的方法试试，本文也会用这种方法继续操作。

打印的大小是越大越好，但扫描的时候需要把色靶和色卡放在一起扫描，所以也不能太大，如果你的色靶大小小于 5*7 英寸，需要在扫描时把精度提升到 400 dpi 以上。

如果你使用的是 RC 相纸，可以选择 premium glossy（因为我的 RC 相纸对标的就是 Epson 的这款产品），或其他光泽相纸选项，不要选择喷墨纸， 这个选项的喷墨量很大，RC 相纸吸收不了，很难干燥。

在打印之后，扫描之前，最好等待 12 小时以上等待相纸上的墨水干燥和稳定。经过我的实际测试，刚打印出来的照片和放置 12 小时以上的照片有可见的色差，在颜色数据上也有较大变化。

2. 扫描

扫描设置为 TIFF 格式，无压缩，尽可能完整还原扫描仪获取的信息。如前文所述，如果你的色靶太小，需要适当提高 dpi，某些额外设置也需要调整。

3. 校色

Profile Prism 软件界面

可以看到软件分为了 3 个 Step。

Step 1

因为 Profile Prism 比较老，不一定包含了市面上所有色卡的参考文件，所以需要在你色卡品牌的网站上下载参考文件，把他放入 Profile Prism 目录里，浏览一下就能找到对应位置，然后在软件里把他选上，并选择 Type 为 Printer。

其他几个设置：

Profile For：Highest Accuracy

White Balance：Allow Profile to Fix WB（对扫描仪校色时使用）

Tone Reprod Curves：Normalize（对扫描仪校色时使用）

Step 2

这里可以让我们在扫描的文件上放置角标来让软件定位，上面 Prism target 是 IT 8 色卡的设置，Printer target 是色靶的设置。

打开扫描文件后，在 Step 2 的 Prism target 中设置四个色卡角标，注意，这里的角标要对齐黑框。

设置色卡角标

在 Printer target 中设置四个色靶角标，注意这里角标是和实际的色块边缘对齐，在色靶上有对应的小的红色角标（图上未标出）。

设置色靶角标

Step 3

都设置好后，软件左下角会分别显示一个直方图，色卡的应当和下图中左侧的类似，色靶的应当和下图中右侧的类似。

直方图，左侧为色卡，右侧为色靶

如果与下图类似，则偏差过大，检查设置。

偏差过大的效果

另外在直方图的右侧，软件会显示一些 Messages，大概看一下，他会告诉你图上有几个标了 “X” 的色块，它们可能会用绿红黑色标出。

绿色 X：表示一些像素处于最小值（阴影阈值）。通常表明有关色块是目标上测量的最暗的。如果只有几个色块包含绿色的“X”标记，则表示没有问题。如果出现大量绿色 “X” 标记，可能意味着颜色处于或接近设备可检测到的最小亮度值，检查设置。

红色 X：红色 “X” 表示某些像素处于最大值（高光阈值）。通常表明有关色块是目标上最亮的。如果只有几个补丁包含红色的“X”标记，则表示没有问题。如果出现大量红色 “X” 标记，可能意味着颜色处于或接近设备可检测到的最大亮度值，检查设置。

黑色 X：表示色块被裁切，不能用来校色。

如果没问题，点击左下角的 Create Profile。

处理完成后，Messages 栏会更新几条信息，可以参考一下决定是否重复校色步骤。

Printer/paper/ink coverage of Lab space：这个阐述了打印机能够印出的色彩在 sRGB 色域中的占比，因为 sRGB 本就有 80% 多的颜色无法打印出来，所以这个百分比在 15%-20% 左右都是正常的。

Printer profile usable range：描述了打印机在 R G B 三个颜色中可打印出的动态范围，0-255 和 26-255 之间是正常的，越接近 0-255 越好。

Smoothing required：说明了 icc 需要进行几次平滑操作来改善颜色，之所以需要平滑，是因为打印出现了色带现象。Profile Prism 最少会进行一次平滑操作，这个数字在 1-4 之间是正常的，越接近 1 次越好。

4. 验证（可选）

打印机保持无色彩控制不变，PS 选择由 PS 控制色彩，选择刚刚输出的 icc 文件，最后打印，你应该能很清晰地看到校色前后的色准变化。（以下是示意图）
